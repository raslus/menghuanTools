# 项目全面检查已解决问题

## Flet 后台任务类型错误

`Page.run_task` 在 Flet 0.86.2 中只接受协程函数。自动 OCR 原先传入同步函数，现已改为异步 UI 应用方法，后台线程不再直接修改主要控件。

## 养成目标操作无效

复制当前属性或清空目标后立即重新读取数据库，导致未保存的界面值被还原。已移除错误的数据库重载，用户可确认界面结果后统一保存。

## 收益金额单位错误

数据库金额以“万”为单位，现统一在绝对值达到 10000 万时显示为亿，其余显示为万，并支持负收益。

## 地图标定误绑定

临时选择的图片可能错误套用同名审核地图的标定。现按绝对文件路径绑定图片与矩阵；重新采集期间旧审核版本和旧矩阵继续生效。

## 账号文件写入与导入完整性

账号文件直接覆盖写入时存在中断损坏风险，导入数据也缺少字段与 ID 校验。现采用原子替换保存，并过滤无效记录、处理重复或缺失 ID。

## 安装与打包配置漂移

项目元数据缺少实际依赖、应用配置仍包含移动端内容，PyInstaller 配置引用未安装的 EasyOCR 和失效临时版本文件。现已按 Windows 桌面与 RapidOCR 主引擎统一。
