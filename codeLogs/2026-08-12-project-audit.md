## 已完成优化

- 将自动 OCR 的 UI 回调改为 Flet 要求的异步 `Page.run_task` 协程。
- 后台地图采集、标定和资源加载通过页面任务更新 UI。
- 修复养成目标复制和清空后被数据库旧值立即覆盖的问题。
- 按“万”为输入单位修复收益金额的万/亿显示。
- 采集地图标定矩阵与具体图片文件绑定，临时选择其他图片时不再误用标定。
- 重新采集地图时保留旧审核图片及其标定，直到新版本审核通过。
- 账号数据采用临时文件加原子替换保存，降低写入中断造成的数据损坏。
- 导入账号时校验数据结构，并统一处理缺失或冲突 ID。
- 同步 `requirements.txt`、`environment.yml`、`pyproject.toml` 和应用配置。
- 移除移动端配置、未安装的 EasyOCR 强制隐藏导入及失效的打包版本文件路径。
- 增加缓存、运行日志、用户采集地图和构建产物忽略规则。
- 运行日志改为滚动文件，单文件 2 MB，保留 3 个备份。
- 重写 README，使其与当前 Windows 桌面功能和目录结构一致。
- 将抓鬼坐标反馈移入识别工作区，消除实时反馈前的额外标签切换。
- 增加无焦点后台识别保护、识别线程代次隔离和 Windows 无激活悬浮窗。
- 重构预测悬浮窗，放大显示并保持地图比例，增加状态标题、最后结果重绘和异常自动恢复。
- 扩大 Windows 工作区，并为养成规划增加实时差值、规则化成长路径与多装备系统检查建议。
