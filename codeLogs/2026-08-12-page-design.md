# 页面设计优化开发日志

- 统一应用名称为“梦幻工具箱”，增加应用副标题。
- 使用 Indigo 色系 Material 3 主题，并统一页面背景、导航和内容留白。
- 为账号管理、收益记账、养成规划、抓鬼辅助增加标题和用途说明。
- 优化账号页搜索、计数、空状态和卡片边界。
- 为记账筛选和养成角色选择增加清晰的视觉分组。
- 按 Windows 桌面端定位将默认窗口调整为 1200×800，并移除主要页面的小屏布局分支。
- 将记账页拆分为明细、分析、汇总三个内部标签，并为明细表增加双向滚动。
- 将账号管理、养成规划和抓鬼辅助按用户任务拆分为内部标签。
- 修正抓鬼预测的 ±30/255 限制，增加规则约束、地图局部样本学习、异常样本抑制和预测可信度显示。
- 完善抓鬼 OCR 文本解析，支持大小鬼分类、任务坐标候选评分，并隔离任务坐标与玩家当前位置。
- 增加小地图框选采集、待审核清单、审核启用和内置资源自动回退流程。
- 为采集地图增加多点仿射坐标标定、误差门槛及预测框像素转换。
- 修复新版 Flet 不再接受 `FilePicker(on_result=...)` 导致的地图图片选择错误。
- 根据实际 Flet 0.86.2 Service API 修正地图选择、账号导入和账号导出文件对话框。
- 保留现有业务逻辑、数据库结构及页面切换机制。
