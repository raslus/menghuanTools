# 结构化装备选择开发日志

## 目标

将养成规划中的六个装备自由文本框替换为可选择、可汇总的当前装备编辑器。

## 完成内容

- 新增六件装备与四件灵饰，共十个装备部位。
- 普通装备支持等级、基础属性、两条附加属性、宝石与锻数、特技、特效、套装/符石效果。
- 灵饰支持等级、主属性、三条附加属性、钟灵石效果与等级。
- 装备以卡片显示摘要，可单件编辑、移除或全部清空。
- 新增 `role_equipment` 表，按角色和部位存储 JSON 数据。
- 旧版六个文字装备字段继续保留，并在首次使用结构化装备时作为历史备注显示。

## 验证

- Python 静态编译通过。
- 结构化装备数据库写入、读取往返验证通过。

## 第二阶段：属性联动与命魂之玉

- 增加命魂基础属性、阳玉魄、阴玉魄编辑入口。
- 阳/阴玉魄记录五色灵尘等级，并提示等级折效边界。
- 玉魄支持主属性、附加属性和奇袭/祝符等特殊效果备注。
- 增加 `role_growth_system` 配置表，保存玉魄、技能换算系数、基础值和手动校正值。
- 当前属性按“基础值 + 装备/玉魄/技能贡献 + 手动校正”重算。
- 引入首次校准，避免已有面板属性和新录入装备发生重复叠加。
- 百分比、暴击、抗性、奇袭等非现有面板字段只记录，不进行不可靠换算。
