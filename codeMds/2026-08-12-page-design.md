# 页面体验优化设计

## 目标

在不改变现有业务功能和数据结构的前提下，降低 Windows 桌面端用户的理解与操作成本，使四个核心页面具有一致的信息层级和视觉语言。

## 设计原则

- 应用使用统一的 Material 3 主题、留白、背景层级与导航样式。
- 每个页面首先说明“这是哪里”和“可以做什么”。
- 高频操作突出显示，导入、导出、删除等低频或高风险操作保持次级层级。
- 空数据、搜索无结果分别给出明确原因和下一步操作。
- 表单和筛选条件使用分组容器，避免与结果区域混杂。
- 仅面向 Windows 桌面端设计，默认窗口为 1200×800，最小窗口为 1000×700。
- 统计、筛选、图表和属性对比固定使用宽屏布局，完整信息保持同屏展示。

## 页面调整

- 账号管理：增加账号数量、搜索结果数量、引导式空状态和首个账号快捷入口。
- 账号管理拆分为“账号列表、数据备份”，将低频的导入导出操作从账号工具栏移出。
- 收益记账：增加页面说明，将筛选条件收纳为独立区域。
- 记账工作区拆分为“明细记录、数据分析、分类汇总”三个内部标签，筛选条件对全部标签生效。
- 明细表格支持工作区内纵向和横向滚动，避免内容超出窗口后无法查看。
- 养成规划：明确角色来源，强化当前角色与成长目标的上下文。
- 养成规划拆分为“属性目标、进度与装备”，底部保存操作对两个标签共享。
- 抓鬼辅助：增加首次使用提示，以步骤标题引导用户先获取任务坐标。
- 抓鬼辅助拆分为“识别与反馈、地图预测、学习统计”，每个工作区独立滚动。
- 坐标识别、预测结果和真实坐标反馈位于同一工作区，保持实时辅助的连续操作路径。
